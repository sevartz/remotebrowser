# mentorstvo
**Идея**:  т.к блокировка vpn в основном поисходит через обрыв соединения при обнаружении транспортного трафика(протокола) по фингерпринту или еще как-то, произошла идея ретранслировать браузерное окно для экстренных ситуаций
### СТЕК
- **Язык / платформа:** C#, .NET 10
- **Web‑фреймворк:** ASP.NET Core
- **Аутентификация:** JWT токены 
- **БД:** internal store (PostgreSQL 18.3 в процессе, переписывание функций под async, релизну ~11.06.2026) 
- **Log/Observability:** структурированные логи(Microsoft.Extensions.Logging)
